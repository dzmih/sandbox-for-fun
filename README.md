# falling sand game

песочница на c++ и raylib
песок вода огонь кислота играть платно

## build

```powershell
cmake -S . -B build
cmake --build build --config Release
.\build\Release\falling_sand.exe
```

## controls

- left mouse paint
- right mouse erase
- middle mouse pick material
- wheel brush size
- q e switch material
- space pause
- n one step in pause
- c clear
- 1 sand
- 2 water
- 3 wall
- 4 wood
- 5 fire
- 6 acid
